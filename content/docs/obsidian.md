[Obsidian](https://obsidian.md/) is a proprietary personal knowledge base and note-taking application that operates on Markdown files.

## Install

**Windows**

```powershell
winget install -e --id Obsidian.Obsidian
```

**Ubuntu**

Download and install the [installer](https://obsidian.md/download).
