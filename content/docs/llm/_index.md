Large language models (LLMs), APIs, agents, and harnesses.

- [LLM models](models.md) : giant tables of numbers
- [LLM front ends](frontends.md) : interacting with engines
- [LLM engines](engines.md) : run LLM models

## Tools

- [llmspeed](https://llmspeed.dev/) : Feel how fast a local LLM runs before you buy the hardware
- [sparkDash](https://github.com/MiaAI-Lab/sparkDash) : Multi-DGX Spark (or machines with NVIDIA GPUs) Monitoring Dashboard

## Benchmarks

- [spark-bench](https://github.com/Weschera/spark-bench) : Mixed-capability LLM benchmark for DGX Spark.
- [tool-eval-bench](https://github.com/SeraphimSerapis/tool-eval-bench) : A tool-calling quality benchmark for LLMs in agentic workflow.
- [QualityBench](https://github.com/launch80/QualityBench) : QualityBench measures how good a model's answers are, and how much quality a quantized build or a different engine loses, against any OpenAI-compatible endpoint.
