[Typst](https://typst.app/) is a markup-based typesetting system that is powerful and easy to learn. (Easy as Markdown, powerful as LaTeX). [GitHub repo](https://github.com/typst/typst)

- [Typst documentation](https://typst.app/docs/)

## Install Typst

[Binary releases](https://github.com/typst/typst/releases/)

Via Winget (Windows):

```sh
winget install --id Typst.Typst
```

- [VSCode extension](https://marketplace.visualstudio.com/items?itemName=myriad-dreamin.tinymist)
