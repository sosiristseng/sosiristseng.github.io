[winget](https://learn.microsoft.com/zh-tw/windows/package-manager/winget/) is a command-line package manager for Windows.

## List of winget packages

- [winget.run](https://winget.run/)
- [winstall](https://winstall.app/)

## winget usage

Update all packages

```powershell
winget upgrade --all
```
